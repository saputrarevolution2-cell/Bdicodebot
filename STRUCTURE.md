# TeleCod Modular Structure

Every page owns its CSS and JS:
- index.html -> assets/css/index.css + assets/js/index.js
- login.html -> assets/css/login.css + assets/js/login.js
- register.html -> assets/css/register.css + assets/js/register.js
- dashboard.html -> assets/css/dashboard.css + assets/js/dashboard.js
- marketplace.html -> assets/css/marketplace.css + assets/js/marketplace.js
- sell-buy.html -> assets/css/sell-buy.css + assets/js/sell-buy.js
- payment.html -> assets/css/payment.css + assets/js/payment.js
- profile.html -> assets/css/profile.css + assets/js/profile.js
- settings.html -> assets/css/settings.css + assets/js/settings.js

Shared components:
- components/navbar.html/css/js
- components/footer.html/css/js

Language:
- assets/js/i18n.js
- language choice persists in localStorage and supports ID/EN.
