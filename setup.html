PasTele Production Configuration

Koneksi database sekarang disimpan di js/config.js, bukan di form login dan bukan di localStorage.

Penting: isi hanya SUPABASE_URL dan SUPABASE_ANON_KEY / publishable key. Jangan pernah memasukkan service_role atau secret key ke frontend.

Langkah

  1. Buka js/config.js.
  2. Ganti YOUR-PROJECT dengan Project URL Supabase Anda.
  3. Ganti YOUR_ANON_OR_PUBLISHABLE_KEY dengan anon/publishable key.
  4. Deploy ulang seluruh folder PasTele.
  5. Jalankan supabase/FIXED-MIGRATION.sql di Supabase SQL Editor.

Keamanan member tetap ditentukan oleh Supabase Auth + RLS + RPC server-side. Anon/publishable key memang dirancang untuk berada di aplikasi browser; yang tidak boleh bocor adalah service-role/secret key.
